# Tool card icons

5 PNGs (256×256, transparent background) from Microsoft's open-source
[Fluent Emoji](https://github.com/microsoft/fluentui-emoji) set, 3D style,
MIT-licensed:

- `quran.png` — Open Book
- `prayer-times.png` — Mosque
- `qibla.png` — Compass
- `tasbih.png` — Prayer Beads
- `ramadan.png` — Crescent Moon

Bundled locally (not hotlinked) on purpose — see the comment in
`components/tools/ToolCard.tsx` for why: the previous tool images were
hotlinked from images.remixer.ai and never reliably loaded once the site
ran outside that AI page builder's own preview.
